# 已知限制

常见问题见 [常见问题](faq.md)，排查步骤见 [故障排查](troubleshooting.md)。

## 检索

**中文查询无法使用全文通路。** 全文检索使用不分词的配置，整段中文会成为单个
token，因此中文查询的全文命中恒为 0，混合检索实际退化为纯向量检索。
中文语料请预期检索质量受限。

> 注：这条声明写于 bigram 投影上线之前，platform 领域的检索面知识库中已有
> 更新的说明。此处刻意保留，用于验证体检能发现过期声明。

**Skill 正文不可检索。** 检索层只索引 L0 card，`SKILL.md` 正文不进索引，
因此召回上限受 card 措辞影响。

**缺少库级路由。** 知识库检索直接命中 chunk，catalog 卡片不参与检索。
知识库数量增长后，无法先通过检索判断该查哪个库。

## 同步

**只支持公开仓库。** 私有仓库、自建 GitLab 与 provider webhook 尚未支持。

**不支持自动回写。** 平台不会向仓库提交 PR 或 MR。

## 知识库

**没有 wiki 编译层。** 目前只有 raw sources 与检索投影，尚未实现平台侧的
wiki 编译、`index.md`、`log.md` 与体检操作。每次查询都从原始 chunk 重新拼答案，
不产生积累。

**没有跨库链接。** 链接图只在 package 内解析，跨知识库的引用不会建链。

## 记忆

**没有 supersede 操作。** 记忆条目只能新增与失效，尚不支持用新条目正式取代旧条目。

**反馈信号未接线。** 数据模型已存在，但尚未接入实际的使用反馈。

**没有会话检查点。** 尚不支持保存与恢复会话上下文。
